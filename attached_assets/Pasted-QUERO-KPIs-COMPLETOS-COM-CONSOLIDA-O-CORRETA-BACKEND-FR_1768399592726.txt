1) Consolidar TODOS os KPIs do resultado da equipe a partir dos KPIs por produto (ajustados).
2) Remover os placeholders “0” e calcular corretamente:
   - KPIs de performance (CAC, LTV, conversão, ticket, NPS etc.)
   - DRE completa
   - Balanço patrimonial (totais consistentes)
3) Exibir “KPIs completos” na página de Análises do aluno (sem poluição: colapsável).

- Não inventar novos dados.
- Não usar LLM.
- Não adicionar dependências.

TAREFA A — BACKEND: Consolidar KPIs por produto corretamente

1) Em server/routes.ts, na rota POST /api/rounds/:roundId/process:

     `const adjustedProductKPIs = applyStrategicImpacts(...)`

     `const productKpisList: ResultCoreMetrics[] = []`
     `productKpisList.push(adjustedProductKPIs)`

2) Substituir a construção atual de `consolidatedKPIs = { ... zeros ... }` por uma função de consolidação.

3) Criar helper novo:
   - Arquivo: server/utils/consolidateKpis.ts
   - Função:
     `export function consolidateKpis(productKpisList: ResultCoreMetrics[]) : ResultCoreMetrics`
   - Estratégia de agregação:
     A) Campos monetários (somar):
        revenue, costs, profit,
        receitaBruta, receitaLiquida,
        impostos, devolucoes, descontos, cpv, lucroBruto,
        despesasVendas, despesasAdmin, despesasFinanc, outrasDespesas,
        ebitda, depreciacao, lair, irCsll, lucroLiquido,
        caixa, contasReceber, estoques, imobilizado, intangivel,
        fornecedores, obrigFiscais, outrasObrig, financiamentosLP,
        capitalSocial, lucrosAcumulados
     B) Campos percentuais/índices (média ponderada por revenue):
        brandPerception, customerSatisfaction, customerLoyalty,
        marketShare, taxaConversao, ticketMedio, nps, tempoMedioConversao,
        cac, ltv
        - Se soma de revenue = 0, usar média simples.
     C) Campos derivados (recalcular a partir dos consolidados):
        margin = profit/revenue*100 (se revenue>0)
        roi = profit/costs*100 (se costs>0)
        razaoLtvCac = ltv/cac (se cac>0)
        margemContribuicao = margin (ou recalcular se existir regra específica)
     D) Totais do balanço (recalcular para consistência):
        ativoCirculante = caixa + contasReceber + estoques
        ativoNaoCirculante = imobilizado + intangivel
        ativoTotal = ativoCirculante + ativoNaoCirculante
        passivoCirculante = fornecedores + obrigFiscais + outrasObrig
        passivoNaoCirculante = financiamentosLP
        patrimonioLiquido = capitalSocial + lucrosAcumulados
        passivoPlTotal = passivoCirculante + passivoNaoCirculante + patrimonioLiquido

4) Em routes.ts:
   - Importar e usar:
     `const consolidatedKPIs = consolidateKpis(productKpisList);`
   - Garantir que o resultado final da equipe (storage.createResult) utilize `...consolidatedKPIs` e NÃO valores “0”.

5) Validar:
